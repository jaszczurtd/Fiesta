# Module envelopes

These VRML models show approximate assembly volumes for the RP2040-Zero,
MCP2515/TJA1050 and DS3231 Mini modules. They use the footprint outlines;
component details and socket bodies are simplified. They are drawn in 0.1-inch
VRML units as expected by KiCad.

The DS3231 model places the module PCB 8.5 mm above the carrier, based on the
reported mounting height. The MCU and CAN models use the same provisional
socket height for the preview. Confirm actual socket, battery and connector
heights against the enclosure; these envelopes are not exact component CAD.
